# Undo Download Manager (مدیر دانلود هوشمند آندو)

> **یک دانلود منیجر پیشرفته و بومی اندروید بر پایه Capacitor، مجهز به موتور قدرتمند استخراج محلی (On-Device Extraction) و سیستم دانلود چنداتصاله.**

---

## 📖 معرفی پروژه (Overview)

**Undo Download Manager** یک اپلیکیشن مدیریت دانلود حرفه‌ای است که برخلاف نمونه‌های مشابه که متکی به سرورهای واسط هستند، عملیات استخراج و پردازش را **۱۰۰٪ بر روی دستگاه کاربر** انجام می‌دهد. این برنامه از قدرت **Capacitor** برای رابط کاربری و یک **پلاگین بومی جاوا (Native Plugin)** برای مدیریت فرآیندهای سنگین دانلود استفاده می‌کند.

---

## 🏗️ معماری سیستم (Architecture)

معماری فعلی برنامه بر سه رکن اصلی استوار است:

### ۱. لایه بومی اندروید (Android Native Layer)
*   **YtDlpPlugin.java:** یک پلاگین اختصاصی Capacitor که وظیفه مدیریت باینری‌های اجرایی و دستورات دانلود را بر عهده دارد.
*   **youtubedl-android:** استفاده از کتابخانه بومی برای اجرای `yt-dlp` درون محیط اندروید (بدون نیاز به Chaquopy یا پایتون سیستم).
*   **Embedded FFmpeg:** برای ادغام خودکار جریان‌های صدا و تصویر (Muxing) با کیفیت بالا.
*   **Direct Downloader:** یک موتور دانلود اختصاصی جاوا برای فایل‌های مستقیم (لینک‌های مستقیم فایل) با قابلیت Resume و چند اتصال همزمان.

### ۲. لایه وب و رابط کاربری (Frontend Layer)
*   **Framework:** React + TypeScript + Tailwind CSS.
*   **Capacitor Bridge:** ارتباط بی‌وقفه بین UI و لایه بومی برای دریافت گزارش‌های لحظه‌ای پیشرفت دانلود.

### ۳. حالت پیش‌نمایش/وب (Secondary Web Mode)
*   برای محیط‌های توسعه یا مرورگر، یک سرور Node.js (`server.ts`) به عنوان پراکسی عمل کرده و عملیات استخراج را شبیه‌سازی می‌کند. در نسخه اندروید، این لایه کاملاً کنار گذاشته شده و همه‌چیز به صورت Native انجام می‌شود.

## ⚡ ویژگی‌های اصلی (Key Features)

*   **استخراج هوشمند:** شناسایی خودکار کیفیت‌ها و فرمت‌های مختلف ویدیو و صدا از بیش از ۱۰۰۰ سایت.
*   **دانلود محلی:** عدم ارسال لینک‌های کاربر به سرورهای خارجی (حفظ حریم خصوصی).
*   **زمان‌بندی پیشرفته:** قابلیت تنظیم ساعت شروع و پایان دانلود برای استفاده از ترافیک رایگان.
*   **مدیریت هوشمند صف:** کنترل تعداد دانلودهای همزمان و اولویت‌بندی خودکار.
*   **Open with App Chooser:** باز کردن فایل‌های تکمیل شده مستقیماً در برنامه‌های پخش‌کننده گوشی (VLC، گالری و ...).

## 📱 بیلد و راه‌اندازی (Build & Setup)

### ۱. نصب وابستگی‌ها
```bash
bun install
```

### ۲. آماده‌سازی اندروید
```bash
bun run build          # بیلد پروژه وب
bunx cap sync android  # همگام‌سازی با پروژه اندروید
```

### ۳. متغیرهای محیطی امضای دیجیتال
برای بیلد نسخه Release، باید متغیرهای زیر را تنظیم کنید:
*   `KEYSTORE_PATH`: مسیر فایل `.jks`.
*   `KEYSTORE_PASSWORD`: رمز عبور Keystore.
*   `KEY_ALIAS`: نام مستعار کلید.
*   `KEY_PASSWORD`: رمز عبور کلید.

## ⚠️ محدودیت‌ها و ملاحظات (Limitations)

*   **YouTube Anti-Bot:** به دلیل محدودیت‌های شدید گوگل و یوتیوب بر روی IPها، ممکن است برخی دانلودهای یوتیوب با خطا مواجه شوند یا نیاز به بروزرسانی مداوم موتور دانلود داشته باشند.
*   **منابع سیستمی:** فرآیند Muxing (ترکیب صدا و تصویر) توسط FFmpeg روی گوشی‌های ضعیف ممکن است زمان‌بر باشد و مصرف باتری را افزایش دهد.
