# Undo Download Manager (مدیر دانلود هوشمند آندو)

> **یک دانلود منیجر پیشرفته و قدرتمند موبایل بر پایه Capacitor + React + TypeScript مجهز به موتور واقعی yt-dlp، سیستم زمان‌بندی هوشمند، بازیابی با Undo و پرداخت درون‌برنامه‌ای دوگانه کافه‌بازار و مایکت.**

---

## 📖 معرفی پروژه (About the App)

**Undo Download Manager** یک اپلیکیشن مدیریت دانلود تمام‌عیار برای اندروید و وب است که با هدف ارتقای تجربه بارگیری فایل‌ها و مدیاها از سراسر اینترنت توسعه یافته است. برخلاف دانلود منیجرهای مرسوم که فایل‌های تصادفی یا شبیه‌سازی‌شده ایجاد می‌کنند، این برنامه به **موتور واقعی استخراج و دانلود رسانه yt-dlp** متصل بوده و قادر است ویدیوها و فایل‌های صوتی را از بیش از ۱۰۰۰ سایت (از جمله یوتیوب، اینستاگرام، تیک‌تاک، توییتر/ایکس، فیس‌بوک، پینترست، آپارات و ...) دریافت کند.

---

## ⚡ ویژگی‌های برجسته (Key Features)

### ۱. موتور دانلود واقعی بر پایه yt-dlp (Real yt-dlp Engine)
* **استخراج مشخصات قبل از دانلود:** شناسایی عنوان، تصویر پیش‌نمایش (Thumbnail)، مدت زمان، سرویس مبدأ (Extractor) و فرمت‌های در دسترس (۱۰۸۰p، ۷۲۰p، ۴۸۰p و فایل صوتی MP3).
* **پشتیبانی از دانلود فایل‌های ویدیویی، صوتی و مستقیم:** قابلیت ذخیره ویدیو به همراه صدا، دانلود جداگانه نسخه صوتی (Audio-Only) و دانلود فایل‌های حجیم عمومی (Zip, ISO, PDF, APK, ...).
* **گزارش لحظه‌ای پیشرفت (Real-time Progress):** نمایش درصد دقیق دانلود، سرعت لحظه‌ای (KB/s یا MB/s)، زمان تخمینی باقیمانده (ETA) و حجم دریافت شده با استفاده از Server-Sent Events (SSE) و پل بومی Capacitor.
* **توقف (Pause)، ادامه‌دهی (Resume) و لغو (Cancel):** امکان مدیریت کامل فرایند دریافت با قابلیت ادامه از نقطه قطع شده.

### ۲. سیستم محافظت و لغو ناخواسته (Undo System)
* هنگام لغو یا حذف یک دانلود، یک نوار اعلان هوشمند با تایمر شمارش معکوس باز می‌شود که به کاربر اجازه می‌دهد تنها با یک کلیک عملیات را **Undo (واگردانی)** کرده و دانلود را بدون از دست رفتن فایل یا تنظیمات بازیابی کند.

### ۳. زمان‌بندی هوشمند دانلود (Smart Scheduler)
* تنظیم بازه زمانی دلخواه (مثلاً ساعت ۲ تا ۷ صبح برای استفاده از اینترنت رایگان شبانه).
* قابلیت توقف خودکار دانلودها هنگام خروج از بازه یا قطع شدن اینترنت.
* فعال‌سازی خودکار و مدیریت صف دانلود در پس‌زمینه.

### ۴. دسته‌بندی خودکار فایل‌ها (Auto Categorization)
* تفکیک خودکار آیتم‌ها بر اساس نوع محتوا:
  - 🎬 **ویدیو (Video)**
  - 🎵 **صدا و موسیقی (Music)**
  - 📄 **اسناد (Document)**
  - 💻 **نرم‌افزار (Software)**
  - 📦 **فایل‌های فشرده (Archive)**
  - 📁 **سایر فایل‌ها (Other)**

### ۵. پرداخت درون‌برنامه‌ای چندگانه و یکپارچه (Cafe Bazaar & Myket Billing)
* معماری **Single APK / Single Build**: نیازی به بیلد جداگانه برای کافه‌بازار و مایکت نیست! سرویس هوشمند برنامه هنگام اجرا بر روی دستگاه، مارکت نصب‌شده کاربر را شناسایی کرده و به صورت خودکار به درگاه مربوطه متصل می‌شود:
  - پشتیبانی از **Poolakey** برای کافه بازار (`@salarizadi/capacitor-cafebazaar-poolakey`)
  - پشتیبانی از **Myket In-App Billing** (`@salarizadi/capacitor-myket`)
  - درگاه اینترنتی جایگزین (Web Gateway Fallback) برای حالت وب و پیش‌نمایش

## 🏗️ معماری ارتباطی و نحوه استفاده از yt-dlp

سیستم به صورت دوگانه (Dual-Mode) طراحی شده است:

```
┌────────────────────────────────────────────────────────┐
│                   React + TypeScript UI                │
│             (App.tsx / ytDlpService.ts)                │
└───────────────────────────┬────────────────────────────┘
                            │
            ┌───────────────┴───────────────┐
            ▼                               ▼
    [حالت وب / سرور لوکال]          [حالت بومی اندروید]
  Node.js / Express Server           Capacitor Bridge
   (ChildProcess yt-dlp)             (YtDlpPlugin.java)
            │                               │
   Server-Sent Events (SSE)         Android DownloadManager
            │                        + Foreground Service
            ▼                               ▼
  دانلود واقعی در دیسک/سرور         دانلود در پوشه Downloads کاربر
```

### بسته‌بندی باینری yt-dlp روی اندروید:
1. **پلاگین بومی YtDlpPlugin:** در پکیج `com.undodownloadmanager.app.plugins.YtDlpPlugin` پیاده‌سازی شده و از `android.app.DownloadManager` همراه با `NotificationChannel` پیشرفته و `Foreground Service` استفاده می‌کند تا دانلودها حتی پس از بستن برنامه ادامه یابند.
2. **پشتیبانی از باینری پایتون / Chaquopy:** برای اجرای مستقیم خود کدهای yt-dlp روی پردازنده‌های ARM/x86 اندروید، می‌توان ماژول پایتون Chaquopy را در `android/app/build.gradle` فعال کرده یا فایل‌های استخراج‌شده را از طریق بک‌اند محلی متصل به اپلیکیشن به کار گرفت.

## 🚀 راهنمای نصب و راه‌اندازی (Getting Started)

### نیازمندی‌ها:
- **Node.js**: نسخه 20 یا بالاتر
- **yt-dlp**: نصب شده روی سیستم (اختیاری جهت اجرای محلی: `brew install yt-dlp` یا `apt install yt-dlp`)
- **Android Studio & SDK**: جهت کامپایل و خروجی APK برای اندروید

### ۱. نصب وابستگی‌ها:
```bash
npm install
```

### ۲. اجرای محیط توسعه (Development):
```bash
npm run dev
```
برنامه روی پورت `3000` اجرا خواهد شد و بک‌اند استخراج و استریم دانلود را آماده می‌کند.

## 📱 بیلد و خروجی اندروید (Build for Android)

### گام اول: بیلد فرانت‌اند و سینک با کپسیتور
```bash
npm run build:android
```
این دستور پروژه را بیلد کرده و خروجی فرانت‌اند را در پوشه بومی `android` قرار می‌دهد.

### گام دوم: باز کردن در اندروید استودیو
```bash
npm run cap:open:android
```

## 🛒 راهنمای بیلد کافه بازار و مایکت (Building for Cafe Bazaar & Myket)

### شناسه برنامه و پکیج‌نیم (Package Identifier):
* **App ID:** `com.undodownloadmanager.app`
* **App Name:** `Undo Download Manager`

### متغیرهای محیطی پرداخت (.env):
یک فایل `.env` بر اساس نمونه زیر در ریشه پروژه قرار دهید:
```env
VITE_BILLING_PROVIDER="universal" # یا "bazaar" یا "myket"
VITE_BAZAAR_RSA_KEY="کلید_RSA_دریافتی_از_پنل_کافه_بازار"
VITE_MYKET_RSA_KEY="کلید_RSA_دریافتی_از_پنل_مایکت"
```

### تعریف محصولات درون‌برنامه‌ای در پنل مارکت‌ها:
برای همگام‌سازی سکه‌ها و اشتراک‌ها، در پنل کافه‌بازار و مایکت شناسه‌های زیر را به عنوان محصول تعریف کنید:
1. `coins_10` (بسته ۱۰ تایی دانلود)
2. `coins_30` (بسته ۳۰ تایی دانلود)
3. `unlimited_1m` (اشتراک ۱ ماهه نامحدود)
4. `unlimited_3m` (اشتراک ۳ ماهه نامحدود)
5. `unlimited_1y` (اشتراک ۱ ساله نامحدود)

### امضای دیجیتال (Signing Config):
تنظیمات امضا به صورت خودکار در `android/app/build.gradle` پیکربندی شده است:
```bash
export KEYSTORE_PATH="my-release-key.jks"
export KEYSTORE_PASSWORD="password"
export KEY_ALIAS="key-alias"
export KEY_PASSWORD="password"
```
سپس بیلد نهایی را با دستور زیر در پوشه `android` تهیه کنید:
```bash
./gradlew assembleRelease
# یا جهت ایجاد Android App Bundle (AAB):
./gradlew bundleRelease
```
